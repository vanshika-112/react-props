
# Cake Cards - React Props Project

A simple React project built to understand and practice **Props in React.js**. This project displays different cake cards, with each card showing the cake's name, price, and a short description using reusable React components.

## 🚀 About the Project

The main goal of this project is to learn how to use **Props** in React and understand how data can be passed from a parent component to child components.

Each cake card is created using a reusable component, and different cake details are passed to it through props.

## ✨ Features

- Displays multiple cake cards.
- Uses reusable React components.
- Passes data using React Props.
- Shows cake name, price, and description.
- Demonstrates component reusability.
- Simple and beginner-friendly UI.

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone <your-repository-link>
```

2. Navigate to the project folder:

```bash
cd cake-cards
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
